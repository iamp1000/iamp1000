### 🎵 AFFECTIVE MUSIC INTELLIGENCE

<p><b>THE PROBLEM</b><br>
Mood and emotional tone in music are easy for humans to feel and surprisingly difficult for software to measure.
</p>

<p><b>THE BUILD</b><br>
A PyTorch pipeline extracts audio features and predicts mood from raw tracks. A FastAPI backend serves the predictions while a Next.js dashboard backed by TiDB turns the output into something you can actually explore.
</p>
